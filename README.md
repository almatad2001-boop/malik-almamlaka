# 👑 ملك المملكة Pro

لعبة استراتيجية أونلاين متعددة اللاعبين مبنية بـ Node.js + Express + Socket.IO.

## المميزات
- 4–12 لاعباً
- 24 إقليماً تفاعلياً على الخريطة
- احتلال الأقاليم والحروب
- اقتصاد، جيش، دفاع، تطوير مبانٍ
- أحداث عشوائية
- تحالفات
- بطاقات استراتيجية
- ترتيب نهائي وملك المملكة
- واجهة متجاوبة للجوال والكمبيوتر

## التشغيل المحلي
1. ثبّت Node.js.
2. افتح مجلد المشروع.
3. شغّل `START-MALIK.bat` أو:
   `npm install`
   `node server.js`
4. افتح `http://localhost:3000`.

> لا تفتح `public/index.html` بالنقر المزدوج إذا كنت تريد اللعب الأونلاين؛ الصفحة تحتاج خادم Socket.IO. زر «استعراض الخريطة» يعمل كمعاينة حتى بدون الخادم.

## Render
Build: `npm install`
Start: `node server.js`

## ملاحظة
حالة الغرف في الذاكرة أثناء تشغيل الخادم؛ للحفظ الدائم والحسابات يمكن إضافة Supabase في مرحلة لاحقة.
